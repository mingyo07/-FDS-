## 💡 추진 배경

- 사회서비스 전자바우처의 서비스·재정 규모가 확대되면서 부정수급의 효과적인 탐지·관리 필요성 증가
- 기존 FDS는 머신러닝(XGBoost, LightGBM) 기반으로, **이용자·제공인력·기관이 서로 연결된 복합 패턴**을 반영하는 데 한계
- 조사 인력·시간이 한정되어 있어, 의심 사례를 많이 찾는 것보다 **실제 부정수급 가능성이 높은 사례를 우선 선별**하는 것이 중요

## 📊 데이터

- **장애인활동지원 전자바우처 결제 데이터 658,876건** (2023.01 ~ 2025.12)
- 라벨 `INJSTUSE_AT` 기준: 부정수급 350,812건(53.24%) / 정상 308,064건(46.76%)

### 전처리

- **결측률 기반 변수 정리** (원본 274개 컬럼)
  - 결측률 80% 이상: 일괄 제거 (단, 결측이 "해당 없음"을 의미하는 변수는 의미 기반 0 대체)
  - 60~80%: 범주형은 부정수급률/Lift, 수치형은 Point-Biserial Correlation + Kruskal-Wallis로 라벨 연관성 검토
- **DDIF(결제시간차 승인건수) 계열 다중공선성 제거**: 86개 → 6개
- **파생변수 생성**: 시간·요일 순환표현(sin/cos), 자정 경과 여부, 정부지원금 비중, 분당 결제금액, 바우처 소진율, 초과청구 지표(시간 차이·비율) 등
- **데이터 누수 방지**: 분할 후 Train 통계값으로만 결측치 대치, 라벨 성숙도 누수 컬럼(`DELNG_MONTH`, `DELNG_QUARTER`) 제외

### 데이터 분할

실제 운영 환경과 유사하도록 Valid/Test의 부정수급 비율을 **8.30%**로 조정했습니다.

| 분할 | 건수 | 양성률 | 용도 |
|---|---:|---:|---|
| Train | 395,733 | 53.32% | 모델 학습 |
| Valid | 67,263 | 8.30% | 튜닝 · 가중치/임계값 결정 |
| Test | 67,227 | 8.30% | 최종 1회 평가 |

## 🧠 모델 구조

```
                    ┌──────────────────────────┐
                    │  관계 네트워크 분석 (Graph) │
                    │  부정 연루율 3종 + 신규노드 2종 │
                    └────────────┬─────────────┘
                                 │ 관계 피처 5종
                                 ▼
 결제 데이터 ──┬──▶ LightGBM (109 피처)            ── S_ML   × 0.55 ─┐
              │                                                    │
              ├──▶ FT-Transformer (93 피처)       ── S_DL   × 0.25 ─┼──▶ S_final ──▶ 0~999 위험점수
              │                                                    │              + SHAP 위험 사유 Top 3
              └──▶ 이상탐지 (Isolation Forest + AE) ── S_ANOM × 0.20 ─┘
```

**최종 점수**

```
S_final = 0.55 × S_ML + 0.25 × S_DL + 0.20 × S_ANOM
```

- 각 축 점수는 순위 백분위로 정규화 후 가중합
- 가중치와 판정 임계값(**0.5319**)은 **Valid에서 결정 후 동결**, Test에는 그대로 1회만 적용

| 구성 요소 | 상세 |
|---|---|
| **LightGBM** (주 분류기) | 관계 위험 피처 5종 포함 109피처, Optuna 30회 튜닝, 5시드(42, 7, 123, 2024, 99) 앙상블 + Isotonic 캘리브레이션 (ECE 0.0689 → 0.0035) |
| **FT-Transformer** (딥러닝) | 93피처를 96차원 토큰으로 임베딩, 3층 Transformer · 8-head attention, AdamW(lr 1e-4) · Dropout 0.15 · 조기종료 |
| **이상탐지** (비지도) | Train 정상 184,737건만 학습, 58개 변수, Isolation Forest(0.95) + Denoising AutoEncoder(0.05) |
| **관계 네트워크 분석** | 이용자·제공인력·기관 간 관계에서 부정 연루율 및 신규 노드 플래그를 추출해 LightGBM 입력으로 사용 |

### 주요 인사이트

- **관계 정보의 기여가 가장 큼**: 관계 피처 5종 추가 시 검증 F1 **0.7319 → 0.8239 (+0.0920)**, 단일 요소 기준 최대 개선
- **앙상블 결합 기여** (Test 구성별 최적 임계값 기준): LightGBM 0.8250 → +FT-Transformer 0.8371 (+0.0121) → +이상탐지 0.8362
- **SHAP 상위 변수**: 관할 부서 · 이용자 연령 · 제공기관 시군구 · 제공인력 연령 · 장애 유형
